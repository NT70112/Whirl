# Whirl

**Whirl** — учебный проект, представляющий собой вёрстку сайта по готовому макету из Figma: [Figma](https://www.figma.com/design/IuTcKXrTzQBzWG9a0EZTmJ/Whirl--Copy---Copy-?node-id=0-1&t=NbmCt3rutusGuVVI-1).

## Структура проекта

Проект состоит из двух страниц:

- `index.html` — главная страница, свёрстанная по готовому макету.
- `form.html` — дополнительная страница с самостоятельно разработанной формой обратной связи.

## Логика взаимодействия

Логика взаимодействия пользователя со страницей написана с использованием библиотеки **jQuery**, которая в этом проекте выполняет функцию обработчика нажатий пользователя.
